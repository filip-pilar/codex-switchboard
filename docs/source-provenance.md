# Source provenance and adaptations

All four archive SHA-256 values in `references/manifest.json` were verified before extraction. Every recorded gateway/router working-tree file hash was also verified. `bin/extract-references.py` rejects absolute paths, traversal, symlinks and special members, and extracts only into ignored `references/extracted/`. The archives have not been changed. No upstream instructions were installed as project instructions.

## Mechanical decisions and evidence

- Account-profile state is partitioned under the app's `native/` directory by effective Codex home. This avoids colliding with the helper-owned settings/registry. The app owns profile credentials; the helper owns routing/catalog/install state through private stdio.
- Bun **1.4.2 (744846f84)** is the installed build runtime, replacing the snapshot's package-manager declaration of 1.3.5. The actual compiled helper passed gzip/zstd and decompressed-size checks. The official runtime notice and linked-library inventory are included in `licenses/`, with download URL and SHA-256 provenance. Provider CLIs are not bundled.
- The installed native app is `/Applications/ChatGPT.app`, with `Contents/Resources/codex`. Its stdio interface, combined picker catalog, `max` reasoning, local sentinel, `/codex/v1/responses` suffix, SSE, and 426 fallback were observed using isolated, local-only fixtures.
- An AppKit status item and popover host the SwiftUI menu; the Manage window includes Show Menu so its controls remain easy to reach even with a crowded macOS menu bar. Ordinary Quit and Command-Q both use the integration warning.
- Initializing provider-private environment **before** any upstream catalog import is required: the pinned dependency snapshots host, port, credentials and model defaults at module load. A focused check verifies that discovery-before-start still binds only to loopback on an ephemeral private port.
- Unknown provider context sizes remain unknown in the registry/UI. Catalog entries use a documented conservative local budget of 32,768 tokens. Unknown Grok effort/vision capabilities are not advertised. Astra efforts are grouped only by the reviewed exact overlay; other discovered selectors stay distinct.
- Devin compatibility also checks the pinned resolver for exact selector equality. The live worker repeats that check before forwarding, so stale cached metadata cannot silently remap a request or degrade it to a free selector. Remapped discoveries are listed as requiring an adapter update.
- Discovery refreshes preserve preferences and do not stage a restart when picker metadata is unchanged. A changed official CLI identity invalidates the prior entitlement scope before another request is admitted. Existing selected models are not silently replaced on failure/removal.
- Restore preserves a later valid native model together with native-provider selection when reinstating an old external provider would invalidate it. The original external provider table remains available. This applies the plan’s later-native-choice rule without creating an unusable model/provider combination.
- Hidden, exact-selector compatibility entries preserve applied legacy tasks; native slugs remain native. External compaction and unclassifiable private continuation fail explicitly instead of losing context or falling back.
