# Continue implementation

Reusable task prompt for continuing product work with a coding agent. This replaces the completed initial kickoff; it does not itself authorize activation or inference.

> Continue Codex Switchboard from the current implementation checkpoint. Use `AGENTS.md` for workflow boundaries and `docs/implementation-status.md` for recorded progress. Identify the remaining outcome relevant to my request, consult the corresponding sections of `docs/implementation-plan.md`, and carry authorized work through implementation, affected checks, and repairs. Use `docs/development-workflow.md` to select checks and understand their prerequisites. Preserve completed work and distinguish prior evidence from checks run now. Report the runnable artifact’s absolute path when app code changes, remaining user-dependent evidence, and the applicable setup/restore steps.

For a bounded fix, replace the first sentence with the specific outcome. Do not turn a maintenance request into the original full-product implementation run.
